
### 🐳 Terminal Powershell Commands

### Start a Service :

```powershell
Start-Service -Name "Apache2.4"
```
### Stop a Service :
```powershell
Stop-Service -Name "Apache2.4"
```
### Restart a Service :
```powershell
Restart-Service -Name "Apache2.4"
```

### Status Check :
```powershell
Get-Service -Name "Apache2.4","mysql"
```

## 📊 Windows Service Name Like :

| Service Name | Cmd |
|---------|----------|
| MySql | mysql |
| Apache | apache2.4|
