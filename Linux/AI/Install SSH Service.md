
### 🐳 How to install open code AI on linux

> [!IMPORTANT]
### Official web site [OpenCodeAI](https://opencode.ai/)

#### Step 1: Install npm package :
```bash
sudo apt install npm -y
```
> #### or 

#### Step 2: Install opencode For CLI
```bash
npm install -g @opencode/cli
```

#### Step 2: Install opencode For Desktop | Download deb pkg and then install
```bash
sudo apt install ./opencode_pkg.deb
```

#### Step 3: Allow on Firewall

```bash
sudo ufw allow ssh
sudo ufw status
```
> [!NOTE]
> Enable and disable firewall

```powershell
sudo ufw enable
sudo ufw disable
```
